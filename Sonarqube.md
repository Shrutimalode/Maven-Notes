# Sonarqube

Sonarqube is an opensource tool that automatically inspects the source code to detect bugs, security and code quality issues helping the developers to write clean, safe and maintainable code

**OR**

It is source code analyzing tool which is used to scan the source and generate a report in the metrics format

## To implement Sonarqube

1. Launch 2 instance, One is for "Maven" and one is for "Sonarqube"
   - --> with instance type "t2.medium"
   - --> OS as "Ubuntu" --> Storage (10/15GB)

2. In Maven Instance Install the tools that are given below

   **Commands:**
--> sudo apt update
--> sudo apt install openjdk-17-jdk -y
--> sudo apt install maven -y
3. Clone the spring-petclinic-framework repository into maven instance

   **Commands:**

--> git clone <spring-petclinic-framework-URL>


4. Get inside the project --> Verify pom.xml is present and later generate a build using the command

   **Commands:**

--> mvn package


5. Connect Sonarqube instance and follow the below steps

   - --> Go to instance dashboard
   - --> Select the sonarqube instance go to security
   - --> Click on security group link and click on add rule and enable the port number "9000"
   - --> Click on save rule
   - --> Download the sonarqube from the website using the wget command

   **Commands:**

--> wget -O sonar.zip <sonarqube-download-communitylink>


6. Unzip the downloaded archive file and install Java-17 software

   **Commands:**

sudo apt install unzip
unzip sonar.zip
sudo apt install openjdk-17-jdk -y


   - Go inside sonarqube folder and follow the below path

     **Path:**
 /bin/linux-x86-64

   - Run the script that is sonar.sh

     **Command:**
 ./sonar.sh start

   - Go to the browser and paste the public IP of the Sonarqube instance with port number "9000"

7. Login to the sonarqube by using username and password as "admin"
8. Change the password based on the requirements specified

## To create a project in Sonarqube follow the below steps

1. Create a project by clicking on create local project
2. Give the project name to display and make the project key is generated by its own
3. Click on create project the project will be created
4. To analyze the project click on Locally
5. Generate a token for the project by using the token name
6. And select the tool "Maven"
7. Copy the command which is displayed and paste it in the maven instance
8. Now go back to the Sonarqube and the report will be generated in a metrics format
